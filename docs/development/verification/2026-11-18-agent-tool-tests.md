# Agent 工具装配与调用测试

测试对象为 2026-11-18 本机 `feat/chat-composer` 工作区，基准提交为 `f1c3af2`，包含当时未提交的修改。后端按 `uv.lock` 建立独立 Windows 测试环境，数据库用项目配置的 PostgreSQL 测试库。本文记录测试结果，阶段状态仍以项目阶段计划为准。

## 快照恢复异常

通过 `ChatRuntime._execute` 进入运行流程，在隔离测试中令快照恢复返回错误，并在默认装配入口截断执行。观察到默认装配调用 1 次、模型调用 0 次。这个结果验证了运行时会进入默认装配分支。测试未执行后续业务工具，也未验证任何数据访问。
