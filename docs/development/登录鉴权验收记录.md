## 初始化与手工验收

当前没有替操作者设置默认密码。首次在 backend 执行：

~~~bash
uv run python -m app.cli.accounts init --username admin --claim-legacy
~~~

按提示设置 12–128 字符密码，再重启前后端，打开 /login。已有账号跳过 init；忘记密码使用 reset-password。--claim-legacy 会显式认领原本无归属的历史对话，不覆盖已拥有记录。若旧运行未结束而认领拒绝，先不带认领标志初始化，登录触发旧运行收敛，再单独 claim-legacy。

手工验收：登录后刷新恢复会话 → 查看原历史 → 新建问答 → 切换空间 → 退出 → 浏览器后退/刷新不能重新取得业务数据。浏览器自动化宿主此前不可用，本次只有组件、API 和真实 TCP 验证，不宣称完成视觉验收。

当前不含网络成员管理/空间管理页面、自定义角色、找回密码、SSO/MFA 或公网级限流。仍仅本机单执行进程运行。未提交、推送或发布应用。
