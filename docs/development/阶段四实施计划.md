## 4.1 交付设计

首个工具 get_my_run_stats 查询本地真实 PostgreSQL，返回当前用户在当前空间最近 1–90 天的运行数量和状态分布，包含本次运行。使用真实应用记录，避免把演示销售数据当作企业系统接入。

身份与空间从执行中 Run → Conversation 的归属关系加载，模型只可提供 days。管理员仍无法查询他人的私有记录。调用前后复核账号、空间、成员和运行状态。工具没有任意 SQL、网络、文件或写业务数据权限。

统一 ToolExecutor 负责白名单、严格参数、时间限制、单次运行调用次数和持久化审计；Deep Agents 模型层只暴露允许的工具，执行层再次阻断内置文件/执行/task 等能力。每个执行使用独立数据库会话；摘要过程仍禁用工具。未来 MCP 复用同一服务入口。

审计关联 Run，保存工具标识、合法的天数参数、状态、聚合结果与安全错误码，不保存密码、会话、模型原始参数、问题或消息正文。问答页展示调用状态和结果；工具失败不伪装成功。
