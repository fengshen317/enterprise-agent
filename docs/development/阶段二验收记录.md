## 真实模型验证

读取用户已配置的本地密钥，在专用测试库执行两次短调用：第一轮记住随机代号，第二轮询问该代号。

- 两个 Run 均 completed，error_code 为空。
- 第二轮正确引用第一轮代号，context_remembered=true。
- 四条用户/助手消息已持久化。
- 临时验收对话及其消息、运行记录已清理，不修改开发库业务记录。
- 不打印或保存密钥；验收摘要仅包含状态、长度与布尔结果。

自动化 pytest 使用可控模型或 HTTP 传输替身；上述真实调用属于单独验收，二者明确区分。

测试在回环地址临时启动 Uvicorn，以真实 TCP 客户端订阅 SSE。已验证持久化部分内容可实时到达、订阅断开不会取消后台运行、取消接口保留部分正文并设置终态、重新订阅可收到 cancelled 终态。测试结束关闭临时监听。

## 边界与运行状态

- 当前未实现认证、用户/工作空间隔离、工具/MCP、任务队列和审批，只用于本机单进程开发。
- 浏览器访问宿主不可用，未执行真实浏览器视觉复核；jsdom 与真实 HTTP 测试不等价于视觉验收。
- 检查时本机 8000 仍是旧后端，OpenAPI 不含问答接口；没有结束用户旧进程。更新后需先停止旧进程，再按开发指南重启。
- 没有持久化队列、自动重放或跨进程接管。硬崩溃保留上次已落库内容，重启后的首次问答访问将遗留运行标为失败。
- 不支持多 Worker 指向同一数据库；数据库重启后需要重启后端。
- 未提交 Git、未推送、未发布正式应用。
