# 序列：企业 Agent 工作台

日期：2026-11-02。状态：已确认范围的交互原型。技术方向：Deep Agents + FastAPI + Vue 3。

正式开发的阶段顺序、验收标准和文档交付物见 [项目阶段实施步骤](项目阶段实施步骤.md)。

## 2026-11-05 产品方向修正（优先于下方历史原型）

问答页面是统一工作入口，规划、工具调用和子 Agent 协作直接在对话中完成。简单问题直接回答；复杂目标由主 Agent 按需拆分步骤、委派独立子任务并汇总。用户无需切换任务标签页、填写预算、编辑计划 JSON 或确认每个只读步骤。

计划和执行进度展示在回答下方，可查看子 Agent 结果、停止执行、失败后重试、停止后补充要求。当前已实现单层子 Agent，最多两个并行；知识库、Agent 配置、技能与写操作逐次审批已实现，文件交付物仍属于后续范围。原型目录保持原样，下方“转为任务”和独立任务中心描述是历史评审方案，不作为当前默认交互。

当前实现与验收见 [对话内规划与子 Agent](development/对话内规划与子Agent实施.md)。

## 产品目标

让企业员工通过问答了解知识、讨论思路和连续追问；需要持续执行时，显式转为任务，由专属 Agent 规划和委派并行子任务，在授权范围内读取资料、生成交付物，业务写入经审批后执行。管理员可配置助手、连接与资源边界，并查看执行与审计记录。

## 角色与入口

|角色|主要能力|
|---|---|
|员工|发起问答、连续追问、查看问答记录、转为任务、补充要求、查看自己的任务和交付物|
|审批人|查看被分配的审批，核对具体操作，批准或退回|
|管理员|配置助手、工具连接、知识范围、成员角色；查看审计|

当前原型以管理员视角展示全部页面；角色设置仅保存演示记录，不是实际权限实现。

## 问答用户旅程

1. 工作台默认问答模式，输入问题直接进入对话。
2. 普通咨询不创建任务，不展示任务进度或审批节点。
3. 在同一对话中连续追问，独立保存问答历史，支持搜索与重新打开。
4. 需要生成文件、分析数据或执行操作时，用户点击“转为任务”，可修改目标并确认范围。
5. 创建后保留原对话，并在对话中关联任务。仅打开转换表单不创建任务，取消后仍保留问答。
6. 原型使用明确标注的示例回答，不连接模型；附件和知识库选择仍为演示交互。

## 任务用户旅程

1. 员工选择任务入口或从问答转为任务，输入目标，选择助手和已授权数据范围；无需填写预算。
2. 确认范围后创建任务；后台承接任务生命周期，前端订阅执行进度。
3. 主 Agent 规划步骤，独立子任务并行执行；前端展示步骤结果摘要和来源。
4. 生成报告与结构化建议；敏感写入进入待审批状态。
5. 审批人核对具体操作与参数；拒绝时填写原因，任务退回。
6. 批准后执行端再次检查权限与参数有效性，幂等执行并记录结果。
7. 员工预览或下载交付物，查看来源和操作记录。

## 任务状态与异常

正式实现建议：草稿 → 排队中 → 执行中 → 等待输入/等待审批 → 执行中 → 已完成。
异常终态：执行失败、已取消、审批退回。审批通过是授权结果，不代表业务写入成功；真实执行需独立记录成功、失败或部分成功。

原型简化为执行中、等待审批、已完成、执行失败、已取消、已退回。点击“推进演示”进入待审批；批准后立即模拟完成。所有新增任务暂复用销售分析图，其他模板仅验证入口。

补充要求应记录为任务事件，正式实现中判断受影响的步骤与已批准参数；必要时重新执行与重新审批，不能将页面显示的确认当成实际权限。

## 产品规则

- 身份、租户、授权范围由可信后台绑定，不接受模型自行声明的身份作为授权依据。
- 检索、工具执行、任务恢复、交付物访问和下载均需服务端鉴权。
- 子 Agent 权限只能继承或收窄；独立上下文不等于独立执行环境。
- 原生 Tool 和 MCP 采用统一能力注册信息：稳定标识、版本、参数、权限、风险、审批、超时、并发与幂等要求。
- 审批绑定操作快照、参数摘要与资源版本；参数改变后重新审批，执行前重验权限。
- 网络与凭证按任务最小化授权，Shell 不得绕过工具边界直连敏感系统。
- 展示步骤、调用、结果摘要与来源，不展示模型内部推理。
- 可取消后台任务；重试需要区分读取与有副作用写入，避免重复业务操作。
- 本轮取消预算填写：任务创建、范围确认、Agent 配置和测试均不要求预算输入；用量页保留明确标注的示例计量，后续平台配额另行设计。

## 实现分层

- Vue 3 企业工作台：聊天输入、任务与审批、交付物、管理页面。
- FastAPI 管理层：身份、租户、任务、审批、配置、权限、审计。
- 后台执行服务：任务队列与生命周期、并发控制、取消、事件推送。
- Deep Agents：规划、工具使用、上下文、子 Agent；LangGraph checkpointer 持久化线程。
- 数据层：PostgreSQL 保存业务状态、审批和检查点；对象存储保存文件；检索索引落实访问过滤。
- 工具层：原生 Tool 与 MCP 适配，业务执行端鉴权、审计和幂等。
- 隔离环境：真实沙箱处理代码与文件；不能将宿主 Shell 当成沙箱。
- 长期业务流程复杂后按需引入 Temporal，保持业务流程与 Agent 步骤职责清晰。

## 原型交付与限制

入口：`../prototype/dist/index.html`。静态 HTML/CSS/JavaScript，可直接用浏览器打开，无需安装依赖。

原型为快速评审使用，不是生产 Vue 项目。交互数据保存在浏览器 localStorage；“使用说明 → 重置演示数据”可恢复。没有模型推理、真实连接检测、文件上传、SSO、后台调度或真实资源授权，不要填入真实密钥或敏感业务资料。

管理配置中的助手名称、指令、模型与工具集合可保存；固定审批规则和示例文案用于评审，不代表完整配置引擎。生产落地时需拆分组件与服务，遵循项目 Vue/TypeScript/SCSS 约定。

## 验收场景

1. 新建任务经过范围确认，详情出现目标、状态与协作图。
2. 手动推进到待审批，审批中心出现记录。
3. 拒绝无意见时阻止提交；有意见时任务退回，可重新执行。
4. 批准后任务完成，出现交付物预览与下载。
5. 搜索和状态筛选不改变其他任务；取消后保留执行记录。
6. 配置、成员与连接修改刷新后仍保留；重置后恢复演示初始数据。
7. 桌面与移动端可访问导航和弹窗，弹窗支持 Escape、焦点循环与关闭后焦点恢复。

## 本轮变更验收

- 默认问答，普通提问与连续追问不增加任务数量。
- 问答记录与任务记录分别展示和保存；工作台同时呈现最近对话与进行中的工作。
- 显式转任务需确认范围，并保留来源对话和任务关联。
- 所有预算输入和预算确认信息移除，任务无需金额即可创建。
- 现有并行执行、审批、重试和交付物流程继续可用。
